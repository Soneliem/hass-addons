### [Dashboard2EPaper](./dashboard2epaper)

![Supports aarch64 Architecture][aarch64-shield]
![Supports amd64 Architecture][amd64-shield]
![Supports armhf Architecture][armhf-shield]
![Supports armv7 Architecture][armv7-shield]
![Supports i386 Architecture][i386-shield]

_Capture Home Assistant dashboards and serve optimized images for e-paper displays._

Dashboard2EPaper automatically captures screenshots of your Home Assistant dashboards and processes them for optimal display on e-paper devices. Features include e-paper optimization, HTTP API for device polling, configurable update intervals, and support for multiple display sizes.
